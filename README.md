## 📌 О проекте

Разведочный анализ данных (EDA) базы резюме с сайта hh.ru. 
Цель — выявить факторы, влияющие на желаемую заработную плату 
соискателей, и отработать полный цикл работы с данными: 
от загрузки до выводов.

## 🎯 Какие навыки отражает этот проект

### Работа с данными (Pandas, NumPy)
- **Загрузка и осмотр данных:** `read_csv`, `head`, `info`, `describe`.
- **Преобразование признаков (Feature Engineering):**
  - Извлечение нескольких признаков из одного текстового поля 
    (пол, возраст — из строки "Пол, возраст").
  - Парсинг текста с помощью регулярных выражений 
    (опыт работы в месяцах из строки "Опыт работы 16 лет 10 месяцев").
  - Категоризация городов (Москва, СПб, миллионники, другие).
  - One Hot Encoding для признаков "Занятость" и "График".
- **Работа с валютой:** конвертация зарплат из USD, EUR, KZT, 
  UAH и др. в рубли по курсу ЦБ на дату обновления резюме. 
  Использовал `merge` по дате и валюте.
- **Очистка данных:**
  - Поиск и удаление полных дубликатов (`drop_duplicates`).
  - Обработка пропусков: удаление строк + заполнение медианой 
    (`fillna`).
  - Удаление выбросов: по зарплате (вручную), по возрасту 
    (метод z-отклонения в логарифмическом масштабе), 
    по опыту (аномалии "опыт > возраст").

### Визуализация (Matplotlib, Seaborn)
- **Распределения:** `histplot`, `boxplot`, `kdeplot`.
- **Сравнения категорий:** `barplot`, многоуровневые диаграммы.
- **Взаимосвязи:** `heatmap` (сводные таблицы через `pivot_table`), 
  `scatterplot`.
- **Работа с осями:** `axvline`, подписи, легенды, `tight_layout`.

### Аналитическое мышление
- Формулировка гипотез ("Готовность к переезду повышает ЗП?").
- Проверка гипотез через сводные таблицы и графики.
- Формулировка выводов на основе данных, а не интуиции.

## 🔍 Ключевые выводы

1. **Образование:** соискатели с высшим образованием ожидают 
   зарплату в среднем на 20–30% выше, чем со средним.
2. **Мобильность:** готовность к переезду и командировкам 
   увеличивает медианную желаемую зарплату на 15–25%.
3. **География:** Москва — лидер по медианной зарплате (85 000 руб.), 
   далее СПб (60 000 руб.) и миллионники (40–50 000 руб.).
4. **Возраст:** наибольшие зарплатные ожидания у соискателей 
   36–50 лет с высшим образованием.
